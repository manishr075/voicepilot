How to use VoicePilot with Wispr Flow: Focus the editor below, then use Ctrl+Win (Windows) or Fn (Mac) to start Wispr Flow. Wispr transcribes your speech and inserts it here. To issue a command, say "Shazam, <command>" — VoicePilot will detect it automatically.
Note: VoicePilot receives text that Wispr inserts; it does not start Wispr itself. Browser microphone fallback is intentionally not provided — Wispr Flow is the intended dictation source.

Command reference — say "Shazam, <command>"
Shazam, edit [instruction] Create an AI-powered revision proposal from the current draft.
Shazam, preview Show (and optionally speak) the pending revision.
Shazam, apply Accept the pending proposal and save it to history.
Shazam, discard Reject the proposal; keep the current accepted draft.
Shazam, undo Undo the last accepted change.
Shazam, redo Redo a previously undone change.
Shazam, read Read the accepted draft aloud (browser speech synthesis).
Shazam, remove last insertion Remove the most recent Wispr-inserted segment.
Shazam, keep that Dismiss the off-topic flag and keep the segment.
Shazam, make that a separate note Move the flagged segment to the Notes area.

Known limitations: VoicePilot processes text inserted into this focused editor by Wispr Flow. It cannot hear a wake phrase while Wispr is stopped, nor start Wispr from a web page. Use Wispr Flow's own shortcut (Ctrl+Win/Fn) to activate dictation. Natural-language "edit" commands require a configured AI provider (see README). All other commands work fully offline without any API key.
